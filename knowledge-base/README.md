# Knowledge Base: bộ não thứ hai

Kho ghi chú Markdown cho công việc vận hành, quản lý dự án và brainstorming, tổ chức theo phương pháp PARA và dùng cùng Claude Code. Claude đọc [CLAUDE.md](CLAUDE.md) để biết cách tra cứu và ghi chép.

## Bắt đầu nhanh
1. Có ý tưởng hoặc ghi chú thô: ghi vào `00-inbox/`.
2. Có dự án mới: nhờ Claude "tạo dự án mới X", hoặc chép `templates/du-an.md` vào `10-projects/x/README.md`.
3. Cuối ngày: "ghi nhật ký hôm nay". Cuối tuần: "tổng kết tuần".
4. Cần tình hình dự án hoặc báo cáo: hỏi Claude, Claude sẽ đọc ghi chú rồi trả lời kèm nguồn.

## Cấu trúc
| Thư mục | Nội dung |
|---|---|
| `00-inbox/` | Ghi chú thô chờ phân loại |
| `10-projects/` | Dự án đang chạy, có mục tiêu và hạn chót |
| `20-areas/` | Mảng trách nhiệm dài hạn |
| `30-resources/` | Kiến thức tham khảo dùng lại |
| `40-archive/` | Dự án và tài liệu đã đóng |
| `50-journal/` | Nhật ký ngày và tổng kết tuần |
| `60-reports/` | Báo cáo đã soạn |
| `70-brainstorm/` | Các phiên brainstorm |
| `templates/` | Mẫu: dự án, báo cáo, brainstorm, nhật ký ngày, tổng kết tuần, biên bản họp |

## Nguyên tắc
Ghi nhanh trước, phân loại sau. Không xóa, chỉ lưu trữ. Không lưu mật khẩu hay dữ liệu mật.
